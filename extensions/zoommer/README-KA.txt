ELIO · Zoommer — 1.0.0

ინსტალაცია (Chrome ან Edge)
1. გახსენი chrome://extensions (Edge-ში edge://extensions).
2. ჩართე Developer mode.
3. Load unpacked → აირჩიე ეს საქაღალდე (სადაც manifest.json დევს).
   ELIO · Alta-ს გვერდით შეიძლება იდგეს, ერთმანეთს არ ეხება.
4. განახლებისას ფაილები ჩაანაცვლე და Extensions-ში დააჭირე Reload-ს.

მუშაობა
1. დააჭირე ხატულას → გაიხსნება პანელი.
2. ჩაწერე:
   - ID საიდან / სადამდე — ზუმერის პროდუქტის ID-ები (ერთ ჯერზე 200 000-მდე);
   - მინიმალური ფასი — ამაზე იაფი პროდუქტი ფაილში საერთოდ არ ჩაიწერება;
   - რაოდენობა — რამდენი პროდუქტი შეაგროვოს (0 = ყველა; საცდელად 3);
   - პაუზა — მოთხოვნებს შორის, მილიწამებში (მინიმუმ 400, ჩვეულებრივ 1000).
   „მხოლოდ მარაგში“ და „ფოტოების გარეშე“ ფაილს კიდევ უფრო ამცირებს.
3. „დაწყება“. ზუმერი იხსნება ცალკე ჩანართში — ის არ დახურო. პანელი ღია დატოვე.
   პაუზა / გაგრძელება მუშაობს; პანელის ან ბრაუზერის დახურვის შემდეგაც
   შეგროვებული არ იკარგება — გახსენი და დააჭირე „გაგრძელებას“.
4. თუ ზუმერი შემოწმების გვერდს აჩვენებს, შეგროვება ჩერდება და ზუმერის ჩანართი
   გამოჩნდება. გაიარე შემოწმება და დააჭირე „გაგრძელებას“.
5. ჩამოტვირთვა — ყველაფერი ერთ ფაილად. ბრაუზერი გკითხავს, სად შეინახოს; ფაილი
   პირდაპირ დისკზე იწერება, ამიტომ დიდი სიაც არ აჭედებს (ადმინი 500 MB-მდე იღებს).
6. elivo.ge/admin → JSON იმპორტი → მომწოდებელი „Zoommer“ → ფაილი → ნახვა → შენახვა.
   ნაწილები სათითაოდ ატვირთე.

რას აკეთებს
- იგივე წესებს იყენებს, რაც იმპორტი: SKU = ZOOM- + ბარკოდი, ფასი ზუმერის ფასი +
  ადმინში მითითებული ფასნამატი, მარაგი — თბილისის ფილიალებიდან.
- ცარიელი ID-ები, იაფი და (თუ მონიშნულია) მარაგის გარეშე პროდუქტები
  ფაილში არ ჩაიწერება — მხოლოდ ითვლება.
- ფოტოები: პირველი 8. AVIF ან დიდი ფოტო JPEG-ად გადაიხატება
  (ფოტოზე ≤ 1 MB, პროდუქტზე ≤ 2 MB). სერვერს ზუმერთან დაკავშირება არ სჭირდება.
- ქსელის შეცდომით გამოტოვებული ID-ები „შეცდომების თავიდან ცდით“ მეორდება.
